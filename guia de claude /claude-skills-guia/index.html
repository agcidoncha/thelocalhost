SKILLS

Un Skill es una receta de trabajo reutilizable que le explica a Claude cómo hacer bien una tarea.

TÚ “Revisa el SEO de esta web”
→
SKILL Cómo revisar SEO
→
CLAUDE Sigue la receta
→
RESULTADO ✓ Revisión hecha
SI SOLO RECUERDAS UNA COSASKILL = CÓMO HACER ALGO
01

¿Para qué sirve?

Para no tener que explicarle a Claude la misma forma de trabajar una y otra vez.

SIN SKILL

“Primero revisa esto, después aquello, no cambies esto, comprueba aquello…”

Cada vez vuelves a explicarlo.
VS
CON SKILL

“Revisa esta web.”

Claude ya tiene la receta.
02

¿Qué hay dentro?

ARCHIVO PRINCIPALSKILL.md

Qué hace · cuándo usarlo · pasos que debe seguir Claude.

+
Ejemplos Así debería hacerse
Scripts Automatizan partes técnicas
Plantillas Recursos reutilizables
Referencias Información de apoyo

No todos los Skills necesitan extras. SKILL.md es la pieza fundamental.

03

¿Cómo sabe Claude cuándo usarlo?

1Pides una tarea“Hazme una factura”
2Claude detecta el SkillLa descripción coincide con tu petición.
3Lee SKILL.mdCarga las instrucciones cuando hacen falta.
4Sigue los pasosPuede usar archivos, scripts, terminal o herramientas.
04

¿Cuándo crear uno?

✓ SÍ

Repites las mismas instrucciones.

Hay un procedimiento concreto.

Quieres resultados consistentes.

× NO

Es una tarea puntual.

Solo quieres guardar información.

No existe un procedimiento especial.

05

Global o de proyecto

GLOBALLo reutilizas en muchos sitios.

Ejemplo: revisar accesibilidad de cualquier web.

PROYECTOSolo tiene sentido en un proyecto.

Ejemplo: publicar productos siguiendo las reglas concretas de una tienda.

08

¿Cómo debe ser un buen Skill?

01 Una tarea concreta
02 Descripción clara
03 Pasos cortos y ordenados

05 Sin relleno ni reglas innecesarias
09

Y sí: existe un Skill para crear Skills.

skill-creator guía a Claude para diseñar un nuevo Skill, crear su SKILL.md, añadir recursos y probar que se activa correctamente.

Un Skill no es magia.

Es una forma de guardar cómo quieres que Claude haga una tarea para poder reutilizar ese procedimiento cuando lo necesites.
